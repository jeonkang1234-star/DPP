## 쓰는 법

가입 화면에 **표의 상호와 번호를 그대로** 입력하고 같은 줄의 PDF를 첨부한다.
셋 중 하나라도 어긋나면 자동승인이 안 되고 관리자 수동 심사로 넘어간다.

- 문서에 "사업자등록증" 문구가 있는가
- 문서의 등록번호가 입력한 번호와 **정확히** 같은가
- 문서의 상호가 입력한 회사명과 (주식회사/괄호/공백 무시하고) 겹치는가

실패 시연은 상호·번호를 **한빛제강 / 205-86-11222** 로 입력하고
`사업자등록증_실패-번호불일치.pdf` 를 첨부하면 된다.

## 왜 시드 회사(대성제강 등)를 안 쓰는가

`organization` 에 `(country_code, biz_reg_no)` 유니크 인덱스가 있다. 시드로 이미 들어간
번호로 가입하면 조직 생성에서 막힌다. 그래서 데모 가입 전용 회사·번호를 따로 만들었다.

번호는 국세청 체크섬(`KoreanBizRegNoValidator`)을 통과하도록 계산해 넣었다.
아무 숫자나 넣으면 형식 오류로 걸린다.

## 세관 / 시장감독기관은 첨부가 없다

기관 계정(`@customs.go.kr`, `@korea.kr` 등)은 사업자등록증 첨부 없이 가입되고,
자동승인을 아예 시도하지 않고 **항상 관리자 수동 심사**로 간다.
운영자(`ops@ieum.io`) 로 로그인해 회원 관리에서 승인해야 로그인이 열린다.

## 다시 만들기

```bash
python3 docker/mock-documents/generator/biz_reg_certs.py
```

파서 통과 여부까지 확인하려면 `parser/biz_reg.py` 의 `extract_biz_reg_fields` +
`verify_against_signup` 에 직접 넣어 보면 된다.
